# Sunken Sanctum

A first-person, grid-based dungeon crawler that runs in a web browser. A town above; below it, old stone halls sunk into the roots of a drowned forest.

Play it at **https://xerafinatalesedrin.github.io/sunken-sanctum/**

## Play

- Single player, with a party of one to four characters.
- Two ways to play: the written campaign, or a random five-level dungeon that is different every new game.
- Four guilds (Fighter, Rogue, Wizard, Cleric) and four races.
- Point-buy character creation.
- Six trainable skills: Lore, Perception, Disarm, Locks, First aid, Armor use. Each guild pays its own price per rank.
- Unidentified treasure, trapped and locked chests, hidden doors.
- Fallen characters can be carried home, rescued, and raised at the temple.

Move with the arrow keys or W A S D. F searches, M shows the map, Enter takes stairs. On a phone, use the buttons under the view.

The game saves in the browser it is played in. Settings has a save code for moving a game to another device.
